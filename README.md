# -
用于在Windows端安卓模拟器上的学习强国刷分

换到另一台电脑运行前的准备清单
==================================================

1. 安装 Python 依赖（命令行执行）：
       pip install -U uiautomator2
   建议 Python 3.12/3.13（3.14 太新，部分库可能编译失败）。

2. 安装 MuMu 模拟器，在里面装好「学习强国」App，并手动登录一次。
   登录状态保存在模拟器里，脚本不处理登录。

3. 修改脚本 学习强国刷分.py 开头的配置区，改成这台电脑的实际情况：
   - ADB_PATH      改成本机 MuMu 安装目录下的 adb.exe
                   （通常在 MuMu\nx_main\adb.exe）
   - MUMU_MANAGER  改成同目录下的 MuMuManager.exe
   - MUMU_INDEX    多开时改成对应实例号（默认 0）
   - ADB_ADDR      端口不对时改成实际端口（默认 127.0.0.1:7555）

4. 直接运行 学习强国刷分.py：
   脚本会自动启动模拟器、等待开机、连接 adb、拉起 App，然后刷文章和视听。
   无需手动开模拟器。

5. 注意：
   - 首次连接时 uiautomator2 会往模拟器里装一个服务组件，
     模拟器需能联网或已开启允许安装。
   - 已读记录按日期跨天去重，只要本目录下的 已读记录.txt 跟着同步过去即可。
